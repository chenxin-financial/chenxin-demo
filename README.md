# 宸信金融顧問｜網站示範版

> ⚠️ 這是**展示用**的靜態版本，給客戶預覽設計與操作流程使用。

## 這是什麼

- **前台**：與正式版完全相同的頁面。
- **後台**：`/admin/` — 可直接登入操作，資料由瀏覽器模擬。

| 帳號 | 權限 | 密碼 |
|---|---|---|
| `admin` | 管理員 | `demo1234` |
| `sales01` | 一般人員 | `demo1234` |

## 重要說明

GitHub Pages 只能託管靜態檔案，沒有伺服器。這個版本用瀏覽器端的模擬層
（`demo.js`）取代真正的後端，所以：

- 表單送出的資料**只存在你目前這個瀏覽器分頁**，關掉分頁就消失
- 名單、統計數字都是**假資料**，不是真實客戶
- 不會有任何資料被傳送或儲存到任何伺服器

正式版採用 Node.js 伺服器搭配 SQLite 資料庫，表單會實際寫入、後台可長期查詢。
原始碼位於私有專案 `chenxin-finance-site`。
